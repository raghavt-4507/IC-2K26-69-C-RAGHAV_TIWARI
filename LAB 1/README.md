# Hello World in C

1) Problem Statement:
Write a C program to print **"Hello, World!"** on the screen.
The objective of this program is to understand the basic structure of a C program and learn how to display output using the `printf()` function.


2) Approach:
The program uses the standard input/output library `stdio.h` and the `printf()` function to display the message.

3) Algorithm:
1. Start the program.
2. Include the `stdio.h` header file.
3. Define the `main()` function.
4. Use `printf()` to print `"Hello, World!"`.
5. Return `0` to indicate successful execution.
6. End the program.

4) Program:
#include <stdio.h>

int main()
{
    printf("Hello, World!");

    return 0;
}


5) Time Complexity:
The program performs a single output operation, so its execution time is constant.

6) Space Complexity:
The program uses a constant amount of memory and does not require any additional data structures.


7) Sample Input:
This program does not require any user input.


8) Sample Output:
Hello, World!


9) Learning Outcomes:
* The basic structure of a C program.
* The purpose of the `main()` function.
* How to include a header file using `#include`.
* The use of the `stdio.h` library.
* How to use the `printf()` function for displaying output.
* The purpose of `return 0`.
* How to compile and execute a basic C program.
* How to document a programming problem using a `README.md` file.
